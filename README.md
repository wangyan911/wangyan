# 西南大学附中器材室管理系统

Java 17 + Spring Boot + SQLite 的局域网器材室管理系统。源码已实现登录与角色、器材/分类管理、借出归还、库存盘点、维修状态���用户管理、统计和器材 CSV 导出。

## 功能与权限

- **管理员**：系统全功能、用户与角色管理、分类管理、器材管理、借还、盘点、维修、统计和 CSV 导出。
- **器材管理员**：器材登记、借还、库存盘点、维修、统计和导出。
- **普通借用人**：查看器材、登记自己的借用、查看并归还自己的借用。
- 库存校验：借出、维修、归还和盘点时校验可用数量，避免负库存。
- SQLite 文件 `equipment.db` 在服务运行目录创建。

## 本机开发运行

要求安装 JDK 17 和 Maven 3.8+：

```powershell
mvn clean package
java -jar target/equipment-manager-0.1.0-SNAPSHOT.jar
```

浏览器访问 `http://localhost:8080`。首次启动的临时管理员为 `admin / ChangeMe-2026!`，首次登录后请立即更改默认密码（用户管理 API 支持更新密码；正式交付前应增加密码修改页面）。

## Windows 局域网运行

构建后双击 `启动系统.bat`，其他校内电脑访问 `http://服务器电脑局域网IP:8080`。服务器需要允许 Windows 防火墙 TCP 入站 8080。数据库默认位于服务的当前工作目录；备份前停止服务，再复制 `equipment.db`。

可设置监听端口：`set PORT=8081` 后启动。

## 安全和打包说明

这是目前的可运行源码版本，不是已编译安装包。仓库没有 Windows 构建执行环境，因此尚未生成 `.exe` 安装包。安全方面提供基于 BCrypt 的密码存储、会话登录、角色校验和写操作 CSRF token；初始密码必须更换。建议仅在可信校内网使用，部署前备份数据库并做 Windows 环境构建/验收。二维码标签、完整借用审批、密码修改页面、自动备份与 exe 安装程序尚未实现。

许可证：学校内部使用，后续可按需补充。
